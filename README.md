# 💀 Pull Request Wheel of Death

Not sure who to assign the pull request to? Fret no more. Let the Wheel of Death make the tough decisions so you don't have to. Completely fair, totally random, and absolutely not your fault.

## 🚀 Live App

👉 **[Try it here: Pull Request Wheel of Death](https://ly900.github.io/pull-request-wheel/)**

## ✨ Features

- Spin the wheel to randomly select a PR reviewer from your team
- Add and remove team members
- Filter by role (Devs only / QA only)
- "No repeats" mode to avoid picking the same person twice in a row
- Spin history to track past PR assignees
- Celebratory confetti animation on winner selection
- Multiple winner sound options
